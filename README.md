# 🪔 Interactive Diwali Celebration

> 🌟 **Live Interactive Demo:** [Launch Diwali Web Experience](https://visheshupadhyay39-web.github.io/diwali_c-celebration/)

---

### 📌 Overview
A festive celebration project combining an interactive web experience with foundational C console programming.

### ✨ Features
- **Interactive Web App (`index.html`):**
  - Realistic fireworks canvas animation with touch/click triggers.
  - Interactive glowing Diya with simulated flame physics.
  - Web Audio API cracker sound generator without external audio assets.
  - Personalized greeting card generator with shareable link and PNG export.
- **C Console Program (`main.c`):**
  - Terminal-based ASCII Diya with simulated flickering flame.
  - Formatted styling using ANSI color sequences.
  - Cross-platform screen refresh and delay routines.
